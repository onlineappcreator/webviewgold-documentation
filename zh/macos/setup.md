# 设置 WebViewGold for macOS 桌面应用 – WebViewGold for macOS

> **摘要：** 安装 Xcode，打开 WebViewGold for macOS 项目，在 index.html 中填写您的 URL 并配置 config.json——或打包您自己的本地 HTML 内容。

[文档](../README.md) › [WebViewGold for macOS](README.md) › 设置 WebViewGold

**平台：** macOS · **类别：** 快速开始 · **在线版本：** [www.webviewgold.com/zh/docs/mac/#setup](https://www.webviewgold.com/zh/docs/mac/#setup)

---

使用 WebViewGold for macOS 设置应用需要 Xcode。Xcode 是一款功能强大的集成开发环境(IDE),用于为 iPhone、iPad 和 Mac 等 Apple 设备开发应用。请注意,Xcode 是一个体积较大的程序,可能会占用 Mac 上较多的存储空间。此外,Xcode 仅适用于 Mac,不兼容 Windows 或 Linux。以下是在 Mac 上下载并安装 Xcode 的分步指南:

- 点击这里:[**在 Mac App Store 中下载 Xcode**](https://apps.apple.com/us/app/xcode/id497799835)
- 点击“获取”或“下载”按钮,开始下载过程。
- 下载完成后,Xcode 安装程序将自动启动。
- 请按照安装程序中的说明完成安装过程。
- 安装完成后,请通过“应用程序”文件夹或 Spotlight 搜索打开 Xcode。
- 首次打开 Xcode 时,系统可能会提示您安装额外组件或同意条款和条件。请按照提示完成设置过程。

在下一步中,请**[下载 WebViewGold for macOS](https://www.webviewgold.com/download/mac/)**以创建 macOS 桌面应用。随后,打开 **Xcode 项目文件**:\
![Xcode 项目的主文件](../../assets/macos/img/xcodefile.jpg)

选择 **public 文件夹**并配置 **config.json** 文件:\
![WebViewGold for macOS 的配置文件](../../assets/macos/img/config1.png)

打开 **index.html** 文件以编辑 URL:\
![将您的 Web 应用 URL 插入 index.html 文件](../../assets/macos/img/config2.png)

如果您希望使用**本地 HTML 内容**(而不是远程 URL),只需将 index.html 文件替换为您自己的内容即可。

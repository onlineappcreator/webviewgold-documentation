# iCal 日历 API – WebViewGold for iOS

> **摘要：** 通过 iCal 日历 API 将网页应用中的日历事件添加到原生 iOS 日历中。

[文档](../README.md) › [WebViewGold for iOS](README.md) › iCal 日历 API

**平台：** iOS · **类别：** API 与功能 · **在线版本：** [www.webviewgold.com/zh/docs/iOS/ical-calendar/](https://www.webviewgold.com/zh/docs/iOS/ical-calendar/)

---

WebViewGold 已内置对日历（原名 iCal）的便捷集成支持。

如需在基于 WebView 的 iOS 应用中添加日历条目，只需链接到一个 .ics 文件即可：

```html
<a href="https://www.webviewgold.com/demo/test.ics">Save to Calendar</a>
```

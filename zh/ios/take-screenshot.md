# 截图 API – WebViewGold for iOS

> **摘要：** 通过 JavaScript 以编程方式捕获当前应用屏幕的截图，并进行分享或保存。

[文档](../README.md) › [WebViewGold for iOS](README.md) › 截图 API

**平台：** iOS · **类别：** API 与功能 · **在线版本：** [www.webviewgold.com/zh/docs/iOS/take-screenshot/](https://www.webviewgold.com/zh/docs/iOS/take-screenshot/)

---

WebViewGold 的截图 API 允许您**以编程方式从 WebView 内容截取屏幕截图**，并将其保存到应用用户的照片图库中。此 API 的一个可能用例是，例如，以编程方式保存您 Web 应用中电子票券（用于音乐节、旅行等）的截图，以便在用户离线、无法访问 WebView 内容时（例如身处音乐节现场、在火车上等）也能出示这些票券。\
链接到此类 URL 即可触发截图：

```html
<a href="takescreenshot://">Save</a>
```

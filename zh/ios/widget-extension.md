# Widget Extension – WebViewGold for iOS

> **摘要：** 为您的 iOS WebView 应用添加主屏幕小组件，将用户直接引导至您的网页应用。

[文档](../README.md) › [WebViewGold for iOS](README.md) › Widget Extension

**平台：** iOS · **类别：** 扩展与插件 · **在线版本：** [www.webviewgold.com/zh/docs/iOS/widget-extension/](https://www.webviewgold.com/zh/docs/iOS/widget-extension/)

---

在主屏幕上提供一个图片小组件（SVG 或 PNG）。请按照我们的视频指南激活它，并在 `Config.swift` 中配置 `widgetRefreshTime`（以分钟为单位）和 `widgetfallbackURL`。可以通过从您的 Web 应用加载类似 `widget://https://example.org/image.svg?user=30` 的 URL 来更新小组件图片。

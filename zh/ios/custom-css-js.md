# 自定义 CSS 和 JavaScript API – WebViewGold for iOS

> **摘要：** 将自定义 CSS 样式和 JavaScript 代码注入您的 iOS WebView 应用的任意页面——非常适合仅限应用的调整。

[文档](../README.md) › [WebViewGold for iOS](README.md) › 自定义 CSS 和 JS API

**平台：** iOS · **类别：** API 与功能 · **在线版本：** [www.webviewgold.com/zh/docs/iOS/custom-css-js/](https://www.webviewgold.com/zh/docs/iOS/custom-css-js/)

---

WebViewGold 允许您使用**自定义 CSS** 和**自定义 JavaScript** 自定义应用的外观和功能，无需修改应用的原生代码。以下将介绍如何使用这些功能，让您的应用契合您的品牌和用户体验偏好。

## 如何使用自定义 CSS 为您基于 WebView 的 iOS 应用设置样式

**自定义 CSS** 功能可让您轻松调整应用的外观和感受：

1. 将您的自定义 CSS 代码添加到 **custom.css** 文件中。
2. 保存文件，即可将这些样式应用于 WebViewGold 应用加载的所有网页。

## 使用 CSS 进行自定义的示例

- 更新颜色以匹配您的品牌。
- 添加动画。
- 为文本、按钮及其他元素设置样式。

## 如何使用自定义 JavaScript 增强您应用的行为

借助**自定义 JavaScript**，您可以在不修改原始 Web 应用远程代码的情况下，为用户个性化定制应用功能：

1. 将您的自定义 JavaScript 代码添加到 **custom.js** 文件中。
2. 保存文件，即可将这些脚本应用于应用加载的所有页面。

## 使用 JavaScript 进行自定义的示例

- 创建警报或通知。
- 添加交互式元素或事件驱动的操作。
- 定制用户交互和页面行为。

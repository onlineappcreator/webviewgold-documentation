请不要忘记将您的 [Envato/CodeCanyon 购买代码](https://help.market.envato.com/hc/en-us/articles/202822600-Where-Is-My-Purchase-Code-)添加到您发布的每个应用的 **PURCHASECODE** 字段中。**每个定制并发布的最终产品需要一个许可证。**\
如果符合以下任一情况，您将需要一个 **Envato/CodeCanyon 扩展许可证**：

- 您向用户收取 Play Store 下载费用
- 您的应用将使用应用内购买 API 或应用内订阅 API
- 您在任何市场销售您的最终应用

如果您已经购买了**常规许可证**，可以在[**此处**](https://help.market.envato.com/hc/en-us/articles/115005593503-If-I-choose-the-wrong-license-or-need-to-upgrade-my-license-how-easy-is-it-to-change-to-the-correct-license-)升级现有许可证。或者，如果您不想申请退款或升级许可证，可以将您现有的**常规许可证**重新用于另一个受**常规许可证**涵盖的应用。\

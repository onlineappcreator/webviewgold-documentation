# 自定义 CSS 和 JavaScript API – WebViewGold for Android

> **摘要：** 将自定义 CSS 样式和 JavaScript 代码注入 Android WebView 应用的任意页面——非常适合仅在应用中生效的调整。

**平台：** Android · **类别：** API 与功能 · **在线版本：** [www.webviewgold.com/zh/docs/android/custom-css-js/](https://www.webviewgold.com/zh/docs/android/custom-css-js/)

---

WebViewGold 允许您使用**自定义 CSS** 和**自定义 JavaScript** 来定制应用的外观和功能，而无需修改应用的原生代码。以下是使用这些功能来根据您的品牌和用户体验偏好定制应用的方法。

## 如何使用自定义 CSS 为基于 WebView 的 Android 应用设置样式

**自定义 CSS** 功能可让您轻松调整应用的外观和风格：

1. 将您的自定义 CSS 代码添加到 **custom.css** 文件中。
2. 保存该文件，即可将这些样式应用到 WebViewGold 应用加载的所有网页。

## 使用 CSS 定制的示例

- 更新颜色以匹配您的品牌。
- 加入动画效果。
- 为文本、按钮和其他元素设置样式。

## 如何使用自定义 JavaScript 增强应用的行为

使用**自定义 JavaScript**，您可以为用户个性化应用的功能，而无需更改原始 Web 应用的远程代码：

1. 将您的自定义 JavaScript 代码添加到 **custom.js** 文件中。
2. 保存该文件，即可将这些脚本应用到应用加载的所有页面。

## 使用 JavaScript 定制的示例

- 创建提醒或通知。
- 添加交互元素或事件驱动的动作。
- 定制用户交互和页面行为。

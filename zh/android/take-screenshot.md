# 截屏 API – WebViewGold for Android

> **摘要：** 通过编程方式捕获当前应用屏幕的截图，并使用 JavaScript 进行分享或保存。

[文档](../README.md) › [WebViewGold for Android](README.md) › 截屏 API

**平台：** Android · **类别：** API 与功能 · **在线版本：** [www.webviewgold.com/zh/docs/android/take-screenshot/](https://www.webviewgold.com/zh/docs/android/take-screenshot/)

---

WebViewGold 的截屏 API 允许您**以编程方式从 WebView 内容中截取屏幕截图**并将其保存到应用用户的照片图库中。此 API 的一个可能用例是，例如以编程方式保存 Web 应用中电子门票（用于节日、旅行等）的截图，以便用户离线且无法访问 WebView 内容（例如在节日现场、火车上等）时可以显示这些截图。\
链接到此类 URL 以触发截屏：

```html
<a href="takescreenshot://">Save</a>
```

# iCal Calendar API – WebViewGold for iOS

> **Summary:** Add calendar events from your web app to the native iOS calendar using the iCal Calendar API.

[Documentation](../README.md) › [WebViewGold for iOS](README.md) › iCal Calendar API

**Platform:** iOS · **Category:** APIs & Features · **Online version:** [www.webviewgold.com/docs/iOS/ical-calendar/](https://www.webviewgold.com/docs/iOS/ical-calendar/)

---

WebViewGold is set up for easy Calendar (previously known as iCal) integration.

To add a calendar entry from your WebView-based iOS application, simply link to an .ics file:

```html
<a href="https://www.webviewgold.com/demo/test.ics">Save to Calendar</a>
```

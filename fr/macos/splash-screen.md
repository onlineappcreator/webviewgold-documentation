# Modifier le texte / la durée de l'écran de démarrage (optionnel) – WebViewGold pour macOS

> **Résumé :** Modifiez le texte de l'écran de démarrage dans SplashScreen.xib et sa durée maximale dans Preferences.m de WebViewGold pour macOS.

[Documentation](../README.md) › [WebViewGold pour macOS](README.md) › Écran de démarrage

**Plateforme :** macOS · **Catégorie :** Design de l’app · **Version en ligne :** [www.webviewgold.com/fr/docs/mac/#splash](https://www.webviewgold.com/fr/docs/mac/#splash)

---

Ouvrez le fichier **SplashScreen.xib** dans le sous-dossier *Interface Builder*. Ensuite, double-cliquez sur le texte pour le modifier : \
![Modifiez le comportement de l'écran de démarrage dans votre application WebView Mac](../../assets/macos/img/splash.jpg)\
Si vous souhaitez modifier la durée maximale de l'écran de démarrage, ouvrez le fichier **Preferences.m** dans le sous-dossier *Generic* pour modifier la valeur du délai d'expiration (en secondes) :\
![Modifiez le délai maximal de l'écran de démarrage dans votre application WebView macOS](../../assets/macos/img/splash2.jpg)

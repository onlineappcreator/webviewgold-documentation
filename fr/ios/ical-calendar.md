# API calendrier iCal – WebViewGold pour iOS

> **Résumé :** Ajoutez des événements de calendrier depuis votre application web au calendrier iOS natif grâce à l'API calendrier iCal.

[Documentation](../README.md) › [WebViewGold pour iOS](README.md) › API calendrier iCal

**Plateforme :** iOS · **Catégorie :** API et fonctionnalités · **Version en ligne :** [www.webviewgold.com/fr/docs/iOS/ical-calendar/](https://www.webviewgold.com/fr/docs/iOS/ical-calendar/)

---

WebViewGold est configuré pour une intégration facile du Calendrier (anciennement appelé iCal).

Pour ajouter une entrée de calendrier depuis votre application iOS basée sur WebView, il suffit d'établir un lien vers un fichier .ics :

```html
<a href="https://www.webviewgold.com/demo/test.ics">Enregistrer dans le Calendrier</a>
```

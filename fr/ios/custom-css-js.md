# API CSS et JavaScript personnalisés – WebViewGold pour iOS

> **Résumé :** Injectez des styles CSS et du code JavaScript personnalisés dans n'importe quelle page de votre application WebView iOS, idéal pour les ajustements propres à l'app.

[Documentation](../README.md) › [WebViewGold pour iOS](README.md) › API CSS et JS personnalisés

**Plateforme :** iOS · **Catégorie :** API et fonctionnalités · **Version en ligne :** [www.webviewgold.com/fr/docs/iOS/custom-css-js/](https://www.webviewgold.com/fr/docs/iOS/custom-css-js/)

---

WebViewGold vous permet de personnaliser l'apparence et les fonctionnalités de votre application à l'aide de **CSS personnalisé** et de **JavaScript personnalisé**, sans modifier le code natif de l'application. Voici comment utiliser ces fonctionnalités pour adapter votre application à votre marque et à vos préférences en matière d'expérience utilisateur.

## Comment styliser votre application iOS basée sur WebView avec du CSS personnalisé

La fonctionnalité **CSS personnalisé** vous permet d'ajuster sans effort l'apparence de votre application :

1. Ajoutez votre code CSS personnalisé au fichier **custom.css**.
2. Enregistrez le fichier pour appliquer ces styles à toutes les pages web chargées par votre application WebViewGold.

## Exemples de personnalisation avec le CSS

- Modifiez les couleurs pour qu'elles correspondent à votre identité visuelle.
- Intégrez des animations.
- Stylisez le texte, les boutons et d'autres éléments.

## Comment enrichir le comportement de votre application avec du JavaScript personnalisé

Avec le **JavaScript personnalisé**, vous pouvez personnaliser les fonctionnalités de votre application pour vos utilisateurs sans modifier le code distant d'origine de l'application web :

1. Ajoutez votre code JavaScript personnalisé au fichier **custom.js**.
2. Enregistrez le fichier pour appliquer ces scripts à toutes les pages chargées par votre application.

## Exemples de personnalisation avec JavaScript

- Créez des alertes ou des notifications.
- Ajoutez des éléments interactifs ou des actions déclenchées par des événements.
- Adaptez les interactions utilisateur et le comportement des pages.

N'oubliez pas d'ajouter votre [code d'achat Envato/CodeCanyon](https://help.market.envato.com/hc/en-us/articles/202822600-Where-Is-My-Purchase-Code-) dans le champ **purchasecode** pour chaque application que vous publiez. **Une licence est requise pour chaque produit final personnalisé et publié.**\
Vous aurez besoin d'une **licence étendue Envato/CodeCanyon** si l'un de ces cas s'applique :

- Vous facturez à vos utilisateurs le téléchargement sur l'App Store
- L'API d'achats intégrés ou d'abonnements intégrés sera utilisée dans votre application
- Vous vendez votre application finale sur une place de marché quelconque

Si vous avez déjà acheté la **licence standard**, vous pouvez **mettre à niveau** la licence existante [**ici**](https://help.market.envato.com/hc/en-us/articles/115005593503-If-I-choose-the-wrong-license-or-need-to-upgrade-my-license-how-easy-is-it-to-change-to-the-correct-license-). Sinon, si vous ne souhaitez pas demander de remboursement ni mettre à niveau la licence, vous pouvez réutiliser votre **licence standard** existante pour une autre application couverte par la **licence standard**.\

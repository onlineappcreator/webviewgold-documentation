# API d'indicateur de chargement – WebViewGold pour iOS

> **Résumé :** Affichez ou masquez l'indicateur de chargement natif à la demande et personnalisez l'expérience de chargement de votre application iOS.

[Documentation](../README.md) › [WebViewGold pour iOS](README.md) › API d'indicateur de chargement

**Plateforme :** iOS · **Catégorie :** API et fonctionnalités · **Version en ligne :** [www.webviewgold.com/fr/docs/iOS/loading-sign/](https://www.webviewgold.com/fr/docs/iOS/loading-sign/)

---

L'indicateur de chargement natif iOS de WebViewGold **apparaît automatiquement** lorsque les pages commencent ou finissent de se charger. Cependant, vous pouvez également contrôler manuellement l'indicateur de chargement pour des scénarios en dehors des événements standards de chargement de page. Cela est particulièrement utile pour des processus où la prise de conscience du chargement par l'utilisateur est nécessaire, tels que :

- L'attente dans une file de chat en direct
- L'exécution d'un processus en arrière-plan sur un serveur cloud
- La visualisation de tout autre processus étendu pour informer l'utilisateur

## Utilisation

Pour contrôler manuellement l'indicateur de chargement de votre application WebView, utilisez les liens suivants :

```html
<a href="spinneron://">Afficher l'indicateur de chargement</a>
<a href="spinneroff://">Masquer l'indicateur de chargement</a>
```

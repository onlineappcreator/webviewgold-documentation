# API de capture d'écran – WebViewGold pour iOS

> **Résumé :** Capturez par programmation une capture d'écran de l'écran actuel de l'app et partagez-la ou enregistrez-la, via JavaScript.

[Documentation](../README.md) › [WebViewGold pour iOS](README.md) › API de capture d'écran

**Plateforme :** iOS · **Catégorie :** API et fonctionnalités · **Version en ligne :** [www.webviewgold.com/fr/docs/iOS/take-screenshot/](https://www.webviewgold.com/fr/docs/iOS/take-screenshot/)

---

L'API de capture d'écran de WebViewGold vous permet de **prendre des captures d'écran par programmation** du contenu de la WebView et de les enregistrer dans la galerie Photos de l'utilisateur de votre application. Un cas d'usage possible pour cette API consiste, par exemple, à enregistrer par programmation une capture d'écran de vos e-tickets (pour festivals, voyages, etc.) de votre application web afin qu'ils puissent être affichés lorsque l'utilisateur est hors ligne et ne peut pas accéder au contenu de la WebView (par exemple, sur un site de festival, dans un train, etc.).\
Liez ce type d'URL pour déclencher une capture d'écran :

```html
<a href="takescreenshot://">Enregistrer</a>
```

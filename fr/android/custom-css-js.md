# API CSS et JavaScript personnalisés – WebViewGold pour Android

> **Résumé :** Injectez des styles CSS et du code JavaScript personnalisés dans n'importe quelle page de votre application Android WebView — idéal pour des ajustements propres à l'application.

**Plateforme :** Android · **Catégorie :** API et fonctionnalités · **Version en ligne :** [www.webviewgold.com/fr/docs/android/custom-css-js/](https://www.webviewgold.com/fr/docs/android/custom-css-js/)

---

WebViewGold vous permet de personnaliser l'apparence et les fonctionnalités de votre application à l'aide de **CSS personnalisé** et de **JavaScript personnalisé**, sans modifier le code natif de l'application. Voici comment utiliser ces fonctionnalités pour adapter votre application à votre marque et aux préférences d'expérience utilisateur.

## Comment styliser votre application Android basée sur WebView avec du CSS personnalisé

La fonctionnalité **CSS personnalisé** vous permet d'ajuster facilement l'apparence de votre application :

1. Ajoutez votre code CSS personnalisé au fichier **custom.css**.
2. Enregistrez le fichier pour appliquer ces styles à toutes les pages web chargées par votre application WebViewGold.

## Exemples de personnalisation avec CSS

- Mettre à jour les couleurs pour correspondre à votre identité de marque.
- Intégrer des animations.
- Styliser le texte, les boutons et d'autres éléments.

## Comment améliorer le comportement de votre application avec du JavaScript personnalisé

Avec le **JavaScript personnalisé**, vous pouvez personnaliser les fonctionnalités de votre application pour les utilisateurs sans modifier le code distant original de l'application web :

1. Ajoutez votre code JavaScript personnalisé au fichier **custom.js**.
2. Enregistrez le fichier pour appliquer ces scripts à toutes les pages chargées par votre application.

## Exemples de personnalisation avec JavaScript

- Créer des alertes ou des notifications.
- Ajouter des éléments interactifs ou des actions déclenchées par des évènements.
- Adapter les interactions utilisateur et le comportement des pages.

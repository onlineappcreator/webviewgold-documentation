# API vidéo native avec Picture-in-Picture – WebViewGold pour Android

> **Résumé :** Lisez des vidéos nativement avec la prise en charge du Picture-in-Picture dans votre application Android WebView.

[Documentation](../README.md) › [WebViewGold pour Android](README.md) › API vidéo native (PiP)

**Plateforme :** Android · **Catégorie :** API et fonctionnalités · **Version en ligne :** [www.webviewgold.com/fr/docs/android/native-video/](https://www.webviewgold.com/fr/docs/android/native-video/)

---

L’API vidéo native permet à votre site web de lancer un flux vidéo dans le lecteur natif de l’appareil avec prise en charge du mode Picture-in-Picture. Déclenchez la lecture native en ouvrant un lien avec le préfixe `startnativevideo://videostreamurl=` :

```html
<a href="startnativevideo://videostreamurl=YOUR_VIDEO_STREAM_URL">Play Video in System Video Player with PiP Support</a>
```

L’utilisateur peut continuer à regarder la vidéo dans une fenêtre flottante tout en naviguant dans votre app ou dans d’autres apps.

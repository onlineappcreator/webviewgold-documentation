# API d'indicateur de chargement – WebViewGold pour Android

> **Résumé :** Affichez ou masquez l'indicateur de chargement natif à la demande et personnalisez l'expérience de chargement de votre application Android.

[Documentation](../README.md) › [WebViewGold pour Android](README.md) › API d'indicateur de chargement

**Plateforme :** Android · **Catégorie :** API et fonctionnalités · **Version en ligne :** [www.webviewgold.com/fr/docs/android/loading-sign/](https://www.webviewgold.com/fr/docs/android/loading-sign/)

---

L'indicateur de chargement natif Android de WebViewGold apparaît automatiquement au début ou à la fin du chargement des pages. Cependant, vous pouvez également contrôler manuellement l'indicateur de chargement pour des scénarios en dehors des évènements standard de chargement de page. C'est particulièrement utile pour les processus où l'utilisateur doit être conscient du chargement, tels que :

- L'attente dans une file d'attente de chat en direct
- L'exécution d'un processus en arrière-plan sur un serveur cloud
- La visualisation de tout autre processus prolongé pour informer l'utilisateur

## Utilisation

Pour contrôler manuellement l'indicateur de chargement de votre application WebView, utilisez les liens suivants :

```html
<a href="spinneron://">Show the loading spinner</a>
<a href="spinneroff://">Hide the loading spinner</a>
```

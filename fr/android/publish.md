## Option B) Processus de publication manuel

 **Nous avons mis à jour le nom de package par défaut afin de vous permettre d'utiliser plus facilement un format de nom de package standardisé. Désormais, le nom de package par défaut de WebViewGold pour Android est com.webviewgold.myappname. Vous pouvez facilement le personnaliser avec votre propre nom de package dans votre application.**

Vous ne souhaitez donc pas utiliser notre agréable service de soumission, mais vous voulez vous en charger vous-même ? Bien sûr, suivez ce guide :

<a id="renamepackagename"></a>Dans un premier temps, remplacez le **nom de package** par un nom de package unique.\
**Effectuez une sauvegarde complète de votre dossier de code source avant de renommer le nom de package.**

[![Regarder la vidéo: Compiler et publier votre application sur Google Play](https://img.youtube.com/vi/CONgxLEA8g4/hqdefault.jpg)](https://www.youtube.com/watch?v=CONgxLEA8g4)

*Astuce :* Le [**WebViewGold Cloud Builder**](https://www.webviewgold.com/cloud-builder?ref=android_docs) (module complémentaire payant) gère automatiquement le nom de package et les mises en ligne sur le Play Store, ce qui vous permet d'éviter les étapes manuelles.

Ensuite, envisagez une revue professionnelle de l'expérience utilisateur/UX sur [UXreviewer.io](https://www.uxreviewer.io) ou sur des services similaires afin d'obtenir les meilleurs résultats d'approbation par le Play Store. Une telle revue UX vous aide également à améliorer globalement la fidélisation des clients de votre produit grâce à des suggestions d'amélioration.\

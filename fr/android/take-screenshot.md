# API de capture d'écran – WebViewGold pour Android

> **Résumé :** Capturez une capture d'écran de l'écran actuel de l'application par programmation, puis partagez-la ou enregistrez-la — via JavaScript.

[Documentation](../README.md) › [WebViewGold pour Android](README.md) › API de capture d'écran

**Plateforme :** Android · **Catégorie :** API et fonctionnalités · **Version en ligne :** [www.webviewgold.com/fr/docs/android/take-screenshot/](https://www.webviewgold.com/fr/docs/android/take-screenshot/)

---

L'API de capture d'écran de WebViewGold vous permet de **réaliser des captures d'écran par programmation** à partir du contenu de la WebView et de les enregistrer dans la galerie Photos de l'utilisateur de votre application. Un cas d'usage possible de cette API consiste, par exemple, à enregistrer par programmation une capture d'écran de vos e-billets (pour des festivals, des voyages, …) issus de votre application web, afin qu'ils puissent être affichés lorsque l'utilisateur est hors ligne et ne peut pas accéder au contenu de la WebView (par exemple, lorsqu'il se trouve sur un site de festival, dans un train, …).\
Faites un lien vers ce type d'URL pour déclencher une capture d'écran :

```html
<a href="takescreenshot://">Save</a>
```

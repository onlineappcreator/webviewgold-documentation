# WebViewGold Documentation – Convert Your Website into a Native iOS, Android & macOS App

> Official WebViewGold documentation in Markdown: turn any website, PWA or web app into a native iOS, Android or macOS app — setup guides, native JavaScript APIs and app store publishing.

WebViewGold is a ready-to-use Xcode and Android Studio app template by OnlineAppCreator that wraps your website, PWA, SaaS dashboard, online shop or AI-generated web app into a native app. You keep your website as the single source of truth and switch on native features — push notifications, in-app purchases, AdMob, QR/barcode scanner, biometrics, deep links and many more — through simple configuration options and JavaScript/URL-scheme APIs.

## Frequently asked questions

### What is WebViewGold?

WebViewGold is a native app template for iOS, Android and macOS that converts a website or web app into a store-ready native app. It is sold via Envato/CodeCanyon and documented on [webviewgold.com/docs](https://www.webviewgold.com/docs/).

### Do I need coding skills?

No. You insert your URL and switch options on or off in one configuration file (`Config.swift` on iOS, `Config.java` on Android). Native features are triggered from your web app with simple links such as `rateapp://` or small JavaScript snippets.

### Which websites and frameworks are supported?

Classic HTML/PHP sites, WordPress, PWAs, jQuery Mobile projects and modern web apps built with Lovable, Base44, Bolt, Bubble, React, Vue, Angular or similar builders. You can load a remote URL, bundle local HTML files, or combine both with an offline fallback.

### Can I publish the app to the App Store and Google Play?

Yes. The *Build & Publish* guides explain the manual process. Alternatively, the WebViewGold Cloud Builder builds and uploads your app in the browser, or the WeSetupYourWebViewApp team sets everything up for you.

### Where can I get help?

Use the [WebViewGold Support Center](https://www.webviewgold.com/support-center/) for FAQs and known issues, or contact the team via the *Support & Contact* page of your platform.

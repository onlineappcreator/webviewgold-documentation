# API de CSS y JavaScript personalizados – WebViewGold para Android

> **Resumen:** Inyecte estilos CSS y código JavaScript personalizados en cualquier página de su aplicación Android WebView: ideal para ajustes exclusivos de la app.

**Plataforma:** Android · **Categoría:** API y funciones · **Versión en línea:** [www.webviewgold.com/es/docs/android/custom-css-js/](https://www.webviewgold.com/es/docs/android/custom-css-js/)

WebViewGold le permite personalizar la apariencia y la funcionalidad de su app mediante **CSS personalizado** y **JavaScript personalizado** sin modificar el código nativo de la app. A continuación se explica cómo utilizar estas funciones para adaptar su app a su marca y a sus preferencias de experiencia de usuario.

## Cómo dar estilo a su app Android basada en WebView con CSS personalizado

La función de **CSS personalizado** le permite ajustar el aspecto y la sensación de su app sin esfuerzo:

1. Añada su código CSS personalizado al archivo **custom.css**.
2. Guarde el archivo para aplicar estos estilos a todas las páginas web cargadas por su app de WebViewGold.

## Ejemplos de personalización con CSS

- Actualizar los colores para que coincidan con su marca.
- Incorporar animaciones.
- Dar estilo a textos, botones y otros elementos.

## Cómo mejorar el comportamiento de su app con JavaScript personalizado

Con **JavaScript personalizado**, puede personalizar la funcionalidad de su app para los usuarios sin alterar el código remoto original de la app web:

1. Añada su código JavaScript personalizado al archivo **custom.js**.
2. Guarde el archivo para aplicar estos scripts a todas las páginas cargadas por su app.

## Ejemplos de personalización con JavaScript

- Crear alertas o notificaciones.
- Añadir elementos interactivos o acciones basadas en eventos.
- Adaptar las interacciones del usuario y el comportamiento de la página.

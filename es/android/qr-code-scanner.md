# API de escáner de códigos QR – WebViewGold para Android

> **Resumen:** Abra un escáner de códigos QR nativo desde su aplicación web y procese los resultados mediante URL o JavaScript.

[Documentación](../README.md) › [WebViewGold para Android](README.md) › API de escáner de QR

**Plataforma:** Android · **Categoría:** API y funciones · **Versión en línea:** [www.webviewgold.com/es/docs/android/qr-code-scanner/](https://www.webviewgold.com/es/docs/android/qr-code-scanner/)

---

Para activar el escáner de códigos QR dentro de su app Android basada en WebView, utilice el siguiente formato de enlace HTML:

```html
<a href="qrcode://">Scan QR Code</a>
```

Al hacer clic en este enlace se abrirá la cámara del dispositivo para escanear un código QR, y cualquier URL codificada en el QR se cargará automáticamente dentro de la WebView.

## Casos de uso

- Unir contenido impreso y digital (por ejemplo, escanear un código QR de una revista para abrir una página web).
- Acceso rápido a promociones, información de productos o eventos.
- Enlace seguro de los usuarios a recursos internos de la app o a páginas de aterrizaje específicas.

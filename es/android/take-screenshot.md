# API de captura de pantalla – WebViewGold para Android

> **Resumen:** Realice una captura de la pantalla actual de la aplicación mediante programación y compártala o guárdela con JavaScript.

[Documentación](../README.md) › [WebViewGold para Android](README.md) › API de captura de pantalla

**Plataforma:** Android · **Categoría:** API y funciones · **Versión en línea:** [www.webviewgold.com/es/docs/android/take-screenshot/](https://www.webviewgold.com/es/docs/android/take-screenshot/)

---

La API de capturas de pantalla de WebViewGold le permite **tomar capturas de pantalla de forma programática** del contenido de la WebView y guardarlas en la galería de Fotos del usuario de su app. Un posible caso de uso de esta API es, por ejemplo, guardar programáticamente una captura de pantalla de sus tickets electrónicos (para festivales, viajes, …) de su app web, de modo que puedan mostrarse cuando el usuario está sin conexión y no puede acceder al contenido de la WebView (por ejemplo, en el recinto de un festival, durante un viaje en tren, …).\
Enlace a este tipo de URL para activar una captura de pantalla:

```html
<a href="takescreenshot://">Save</a>
```

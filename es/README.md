# Documentación de WebViewGold – Convierta su sitio web en una app nativa para iOS, Android y macOS

> Documentación oficial de WebViewGold en Markdown: convierta cualquier sitio web, PWA o app web en una app nativa para iOS, Android o macOS — guías de configuración, API JavaScript nativas y publicación en las tiendas.

WebViewGold es una plantilla de app para Xcode y Android Studio lista para usar, desarrollada por OnlineAppCreator, que convierte su sitio web, PWA, panel SaaS, tienda online o app web generada con IA en una app nativa. Su sitio web sigue siendo la fuente única: active funciones nativas —notificaciones push, compras integradas, AdMob, escáner QR/de códigos de barras, biometría, enlaces profundos y mucho más— mediante simples opciones de configuración y API de JavaScript / esquemas de URL.

## Preguntas frecuentes

### ¿Qué es WebViewGold?

WebViewGold es una plantilla de app nativa para iOS, Android y macOS que convierte un sitio o app web en una app nativa lista para las tiendas. Se vende a través de Envato/CodeCanyon y está documentada en [webviewgold.com/docs](https://www.webviewgold.com/es/docs/).

### ¿Necesito saber programar?

No. Introduzca su URL y active o desactive opciones en un único archivo de configuración (`Config.swift` en iOS, `Config.java` en Android). Las funciones nativas se activan desde su app web con enlaces sencillos como `rateapp://` o pequeños fragmentos de JavaScript.

### ¿Qué sitios web y frameworks son compatibles?

Sitios HTML/PHP clásicos, WordPress, PWA, proyectos jQuery Mobile y apps web modernas creadas con Lovable, Base44, Bolt, Bubble, React, Vue, Angular o herramientas similares. Puede cargar una URL remota, empaquetar archivos HTML locales o combinar ambos con una alternativa sin conexión.

### ¿Puedo publicar la app en App Store y Google Play?

Sí. Las guías de *Compilar y publicar* explican el proceso manual. Como alternativa, WebViewGold Cloud Builder compila y sube su app desde el navegador, o el equipo de WeSetupYourWebViewApp lo configura todo por usted.

### ¿Dónde obtengo ayuda?

Consulte el [Centro de soporte de WebViewGold](https://www.webviewgold.com/support-center/) para preguntas frecuentes y problemas conocidos, o contacte con el equipo desde la página *Soporte y contacto* de su plataforma.

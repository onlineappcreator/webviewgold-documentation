# API de captura de pantalla – WebViewGold para iOS

> **Resumen:** Capture mediante programación una captura de la pantalla actual de la app y compártala o guárdela, mediante JavaScript.

[Documentación](../README.md) › [WebViewGold para iOS](README.md) › API de captura de pantalla

**Plataforma:** iOS · **Categoría:** API y funciones · **Versión en línea:** [www.webviewgold.com/es/docs/iOS/take-screenshot/](https://www.webviewgold.com/es/docs/iOS/take-screenshot/)

---

La API de capturas de pantalla de WebViewGold le permite **realizar capturas de pantalla de forma programática** del contenido del WebView y guardarlas en la galería de Fotos del usuario de su aplicación. Un posible caso de uso de esta API es, por ejemplo, guardar de forma programática una captura de pantalla de sus entradas electrónicas (para festivales, viajes, …) de su aplicación web, de modo que puedan mostrarse cuando el usuario esté sin conexión y no pueda acceder al contenido del WebView (por ejemplo, mientras se encuentra en el recinto de un festival, en un viaje en tren, …).\
Enlace a este tipo de URL para activar una captura de pantalla:

```html
<a href="takescreenshot://">Save</a>
```

# API de audio HTML en segundo plano – WebViewGold para iOS

> **Resumen:** Mantenga el audio HTML reproduciéndose en segundo plano de su app WebView de iOS, incluso con la pantalla bloqueada.

[Documentación](../README.md) › [WebViewGold para iOS](README.md) › API de audio HTML

**Plataforma:** iOS · **Categoría:** API y funciones · **Versión en línea:** [www.webviewgold.com/es/docs/iOS/html-audio/](https://www.webviewgold.com/es/docs/iOS/html-audio/)

En algunos escenarios puede resultar útil reproducir contenido de audio incluso después de minimizar la aplicación (por ejemplo, si ofrece una emisión de radio o su música desde la aplicación).

Nuestro vídeo a continuación muestra cómo activar de forma rápida y sencilla el audio HTML en segundo plano para su aplicación iOS, permitiendo que los usuarios reproduzcan audio incluso cuando cambian a otra aplicación en primer plano o cuando bloquean su iPhone o iPad.

# API de CSS y JavaScript personalizados – WebViewGold para iOS

> **Resumen:** Inyecte estilos CSS y código JavaScript personalizados en cualquier página de su app WebView de iOS, ideal para ajustes exclusivos de la app.

[Documentación](../README.md) › [WebViewGold para iOS](README.md) › API de CSS y JS personalizados

**Plataforma:** iOS · **Categoría:** API y funciones · **Versión en línea:** [www.webviewgold.com/es/docs/iOS/custom-css-js/](https://www.webviewgold.com/es/docs/iOS/custom-css-js/)

WebViewGold le permite personalizar el aspecto y la funcionalidad de su aplicación mediante **CSS personalizado** y **JavaScript personalizado** sin modificar el código nativo de la aplicación. A continuación le explicamos cómo utilizar estas funciones para adaptar su aplicación a su marca y a sus preferencias de experiencia de usuario.

## Cómo dar estilo a su aplicación iOS basada en WebView con CSS personalizado

La función de **CSS personalizado** le permite ajustar el aspecto y la sensación de su aplicación de forma sencilla:

1. Añada su código CSS personalizado al archivo **custom.css**.
2. Guarde el archivo para aplicar estos estilos a todas las páginas web cargadas por su aplicación WebViewGold.

## Ejemplos de personalización con CSS

- Actualice los colores para que coincidan con su marca.
- Incorpore animaciones.
- Aplique estilo al texto, los botones y otros elementos.

## Cómo mejorar el comportamiento de su aplicación con JavaScript personalizado

Con el **JavaScript personalizado**, puede personalizar la funcionalidad de su aplicación para los usuarios sin alterar el código remoto original de la aplicación web:

1. Añada su código JavaScript personalizado al archivo **custom.js**.
2. Guarde el archivo para aplicar estos scripts a todas las páginas cargadas por su aplicación.

## Ejemplos de personalización con JavaScript

- Cree alertas o notificaciones.
- Añada elementos interactivos o acciones basadas en eventos.
- Adapte las interacciones del usuario y el comportamiento de la página.

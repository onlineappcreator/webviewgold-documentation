# API de escáner de código QR – WebViewGold para iOS

> **Resumen:** Abra un escáner de código QR nativo desde su aplicación web y procese los resultados del escaneo mediante URL o JavaScript.

[Documentación](../README.md) › [WebViewGold para iOS](README.md) › API de escáner de QR

**Plataforma:** iOS · **Categoría:** API y funciones · **Versión en línea:** [www.webviewgold.com/es/docs/iOS/qr-code-scanner/](https://www.webviewgold.com/es/docs/iOS/qr-code-scanner/)

---

Para activar el escáner de códigos QR dentro de su aplicación iOS basada en WebView, utilice el siguiente formato de enlace HTML:

```html
<a href="qrcode://">Scan QR Code</a>
```

Al hacer clic en este enlace se abrirá la cámara del dispositivo para escanear un código QR, y cualquier URL codificada en el código QR se cargará automáticamente dentro del WebView.

## Casos de uso

- Conectar el contenido impreso con el digital (por ejemplo, escanear un código QR de una revista para abrir una página web).
- Acceso rápido a promociones, información de productos o eventos.
- Enlazar a los usuarios de forma segura a recursos internos de la aplicación o a páginas de destino específicas.

# API de calendario iCal – WebViewGold para iOS

> **Resumen:** Añada eventos de calendario desde su aplicación web al calendario nativo de iOS mediante la API de calendario iCal.

[Documentación](../README.md) › [WebViewGold para iOS](README.md) › API de calendario iCal

**Plataforma:** iOS · **Categoría:** API y funciones · **Versión en línea:** [www.webviewgold.com/es/docs/iOS/ical-calendar/](https://www.webviewgold.com/es/docs/iOS/ical-calendar/)

---

WebViewGold está preparado para una integración sencilla con Calendar (anteriormente conocido como iCal).

Para añadir una entrada al calendario desde su aplicación iOS basada en WebView, simplemente enlace a un archivo .ics:

```html
<a href="https://www.webviewgold.com/demo/test.ics">Save to Calendar</a>
```

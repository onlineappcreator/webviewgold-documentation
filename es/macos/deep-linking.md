El deeplinking («Custom URL Scheme») es un enfoque potente que permite a los usuarios navegar directamente a una página o sección específica de una aplicación desde una fuente externa, como un sitio web, un correo electrónico u otra aplicación. En el contexto de la plantilla de aplicación para macOS de WebViewGold, el deeplinking permite a los desarrolladores crear enlaces que abren la aplicación y llevan a los usuarios a una página concreta dentro de ella.\

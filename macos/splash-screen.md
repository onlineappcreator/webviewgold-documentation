# Change the Splash Screen text/ duration (optional) – WebViewGold for macOS

> **Summary:** Change the splash screen text in SplashScreen.xib and the maximum splash duration in Preferences.m of WebViewGold for macOS.

[Documentation](../README.md) › [WebViewGold for macOS](README.md) › Splash Screen

**Platform:** macOS · **Category:** App Design · **Online version:** [www.webviewgold.com/docs/mac/#splash](https://www.webviewgold.com/docs/mac/#splash)

---

Open the **SplashScreen.xib** file in *Interface Builder* subfolder. Afterward, double click on the text to edit the text: \
![Modify the Splash Screen behavior in your Mac WebView application](../assets/macos/img/splash.jpg)\
If you want to modify the maximum duration of the splash screen, open the **Preferences.m** file in *Generic* subfolder to change the timeout value (in seconds):\
![Edit the Splash Screen maximum timeout in your macOS WebView app](../assets/macos/img/splash2.jpg)

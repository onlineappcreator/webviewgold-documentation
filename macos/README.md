# WebViewGold for macOS Documentation

![WebViewGold for macOS](../assets/macos/img/header.png)

> Official WebViewGold for macOS documentation: convert your website, PWA, SaaS dashboard, or HTML project into a native Mac desktop app with Xcode setup, configuration options, JavaScript APIs, publishing guidance, and SDK-style implementation notes.

[Documentation](../README.md) › WebViewGold for macOS

Convert your website, PWA, SaaS dashboard, e-commerce storefront, or AI-generated web app into a native macOS app in minutes. Use WebViewGold like a lightweight app SDK: configure your URL, enable native APIs, integrate JavaScript bridge commands, and publish a store-ready app without rebuilding your web product from scratch.

WebViewGold works with classic HTML/PHP sites, WordPress, jQuery Mobile projects, and modern web apps created with Lovable, Base44, Bolt, Bubble, React, Vue, Angular, or similar builders. The documentation below explains the setup flow, native feature APIs, security considerations, and publishing steps in a technical, implementation-focused format.

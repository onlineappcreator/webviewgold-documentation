# Natives Video mit Picture-in-Picture-API – WebViewGold für Android

> **Zusammenfassung:** Spiele Videos nativ mit Picture-in-Picture-Unterstützung in deiner Android-WebView-App ab.

[Dokumentation](../README.md) › [WebViewGold für Android](README.md) › Natives Video (PiP) API

**Plattform:** Android · **Kategorie:** APIs & Funktionen · **Online-Version:** [www.webviewgold.com/de/docs/android/native-video/](https://www.webviewgold.com/de/docs/android/native-video/)

---

Mit der Native Video API kann deine Website einen Videostream im nativen Player des Geräts mit Picture-in-Picture-Unterstützung starten. Löse die native Wiedergabe aus, indem du einen Link mit dem Präfix `startnativevideo://videostreamurl=` öffnest:

```html
<a href="startnativevideo://videostreamurl=YOUR_VIDEO_STREAM_URL">Play Video in System Video Player with PiP Support</a>
```

Der Nutzer kann das Video in einem schwebenden Fenster weiter ansehen, während er in deiner App oder in anderen Apps navigiert.

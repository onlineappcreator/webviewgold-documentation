# Screenshot-API – WebViewGold für Android

> **Zusammenfassung:** Erstelle programmgesteuert einen Screenshot des aktuellen App-Bildschirms und teile oder speichere ihn — per JavaScript.

[Dokumentation](../README.md) › [WebViewGold für Android](README.md) › Screenshot-API

**Plattform:** Android · **Kategorie:** APIs & Funktionen · **Online-Version:** [www.webviewgold.com/de/docs/android/take-screenshot/](https://www.webviewgold.com/de/docs/android/take-screenshot/)

---

Die Screenshot-API von WebViewGold ermöglicht es dir, **programmgesteuert Screenshots** vom WebView-Inhalt aufzunehmen und in der Foto-Galerie deiner Benutzer zu speichern. Ein möglicher Anwendungsfall für diese API besteht beispielsweise darin, programmgesteuert einen Screenshot deiner E-Tickets (für Festivals, Reisen, …) deiner Web-App zu speichern, sodass diese angezeigt werden können, wenn der Benutzer offline ist und nicht auf den WebView-Inhalt zugreifen kann (z. B. auf einem Festivalgelände, während einer Zugfahrt, …).\
Verlinke diese Art von URL, um einen Screenshot auszulösen:

```html
<a href="takescreenshot://">Save</a>
```

# API für eigenes CSS und JavaScript – WebViewGold für Android

> **Zusammenfassung:** Füge eigene CSS-Stile und JavaScript-Code in jede Seite deiner Android-WebView-App ein — perfekt für App-spezifische Anpassungen.

[Dokumentation](../README.md) › [WebViewGold für Android](README.md) › Eigene CSS- & JS-API

**Plattform:** Android · **Kategorie:** APIs & Funktionen · **Online-Version:** [www.webviewgold.com/de/docs/android/custom-css-js/](https://www.webviewgold.com/de/docs/android/custom-css-js/)

---

Mit WebViewGold kannst du das Erscheinungsbild und die Funktionalität deiner App mithilfe von **Custom CSS** und **Custom JavaScript** anpassen, ohne den nativen Code der App zu verändern. So verwendest du diese Funktionen, um deine App an deine Marke und deine Präferenzen für die Nutzererfahrung anzupassen.

## So gestaltest du deine WebView-basierte Android-App mit Custom CSS

Mit der Funktion **Custom CSS** kannst du das Erscheinungsbild deiner App mühelos anpassen:

1. Füge deinen benutzerdefinierten CSS-Code in die Datei **custom.css** ein.
2. Speichere die Datei, um diese Stile auf alle von deiner WebViewGold-App geladenen Webseiten anzuwenden.

## Beispiele für Anpassungen mit CSS

- Farben an dein Branding anpassen.
- Animationen einbinden.
- Text, Schaltflächen und andere Elemente gestalten.

## So erweiterst du das Verhalten deiner App mit Custom JavaScript

Mit **Custom JavaScript** kannst du die Funktionalität deiner App für Nutzer personalisieren, ohne den entfernten Code der ursprünglichen Web-App zu verändern:

1. Füge deinen benutzerdefinierten JavaScript-Code in die Datei **custom.js** ein.
2. Speichere die Datei, um diese Skripte auf alle von deiner App geladenen Seiten anzuwenden.

## Beispiele für Anpassungen mit JavaScript

- Warnungen oder Benachrichtigungen erstellen.
- Interaktive Elemente oder ereignisgesteuerte Aktionen hinzufügen.
- Nutzerinteraktionen und Seitenverhalten anpassen.

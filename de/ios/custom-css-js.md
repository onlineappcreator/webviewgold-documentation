# Eigenes CSS- und JavaScript-API – WebViewGold für iOS

> **Zusammenfassung:** Füge eigene CSS-Styles und JavaScript-Code in jede Seite deiner iOS-WebView-App ein – perfekt für App-spezifische Anpassungen.

[Dokumentation](../README.md) › [WebViewGold für iOS](README.md) › Eigenes CSS & JS API

**Plattform:** iOS · **Kategorie:** APIs & Funktionen · **Online-Version:** [www.webviewgold.com/de/docs/iOS/custom-css-js/](https://www.webviewgold.com/de/docs/iOS/custom-css-js/)

---

WebViewGold ermöglicht es dir, das Erscheinungsbild und die Funktionalität deiner App mit **Custom CSS** und **Custom JavaScript** anzupassen, ohne den nativen Code der App zu ändern. So verwendest du diese Funktionen, um deine App an deine Marke und deine Anforderungen an die Nutzererfahrung anzupassen.

## So gestaltest du deine WebView-basierte iOS-App mit Custom CSS

Mit der Funktion **Custom CSS** kannst du das Erscheinungsbild deiner App mühelos anpassen:

1. Füge deinen individuellen CSS-Code in die Datei **custom.css** ein.
2. Speichere die Datei, um diese Styles auf alle von deiner WebViewGold-App geladenen Webseiten anzuwenden.

## Beispiele für die Anpassung mit CSS

- Passe die Farben an dein Branding an.
- Füge Animationen hinzu.
- Gestalte Text, Schaltflächen und andere Elemente.

## So verbesserst du das Verhalten deiner App mit Custom JavaScript

Mit **Custom JavaScript** kannst du die Funktionalität deiner App für die Nutzer personalisieren, ohne den ursprünglichen Remote-Code der Web-App zu verändern:

1. Füge deinen individuellen JavaScript-Code in die Datei **custom.js** ein.
2. Speichere die Datei, um diese Skripte auf alle von deiner App geladenen Seiten anzuwenden.

## Beispiele für die Anpassung mit JavaScript

- Erstelle Warnhinweise oder Benachrichtigungen.
- Füge interaktive Elemente oder ereignisgesteuerte Aktionen hinzu.
- Passe Nutzerinteraktionen und das Seitenverhalten an.

# Screenshot-erstellen-API – WebViewGold für iOS

> **Zusammenfassung:** Erstelle programmgesteuert einen Screenshot des aktuellen App-Bildschirms und teile oder speichere ihn – per JavaScript.

[Dokumentation](../README.md) › [WebViewGold für iOS](README.md) › Screenshot-erstellen-API

**Plattform:** iOS · **Kategorie:** APIs & Funktionen · **Online-Version:** [www.webviewgold.com/de/docs/iOS/take-screenshot/](https://www.webviewgold.com/de/docs/iOS/take-screenshot/)

---

Die Screenshot-API von WebViewGold ermöglicht es dir, **Screenshots programmatisch** vom WebView-Inhalt aufzunehmen und in der Fotos-Galerie deines App-Nutzers zu speichern. Ein möglicher Anwendungsfall dieser API ist beispielsweise das programmgesteuerte Speichern eines Screenshots deiner E-Tickets (für Festivals, Reisen, …) aus deiner Web-App, damit diese angezeigt werden können, wenn der Nutzer offline ist und nicht auf den WebView-Inhalt zugreifen kann (z. B. an einem Festivalort, während einer Zugfahrt, …).\
Verlinke auf diese Art von URL, um einen Screenshot auszulösen:

```html
<a href="takescreenshot://">Save</a>
```

# Widget Extension – WebViewGold für iOS

> **Zusammenfassung:** Füge deiner iOS-WebView-App ein Home-Bildschirm-Widget hinzu, das Nutzer direkt in deine Web-App führt.

[Dokumentation](../README.md) › [WebViewGold für iOS](README.md) › Widget Extension

**Plattform:** iOS · **Kategorie:** Erweiterungen & Plugins · **Online-Version:** [www.webviewgold.com/de/docs/iOS/widget-extension/](https://www.webviewgold.com/de/docs/iOS/widget-extension/)

---

Biete ein Bild-Widget (SVG oder PNG) auf dem Home-Bildschirm an. Aktiviere es gemäß unserer Videoanleitung und konfiguriere `widgetRefreshTime` (in Minuten) und `widgetfallbackURL` in `Config.swift`. Das Widget-Bild kann aus deiner Web-App aktualisiert werden, indem eine URL wie `widget://https://example.org/image.svg?user=30` geladen wird.

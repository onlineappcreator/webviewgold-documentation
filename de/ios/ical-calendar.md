# iCal-Kalender-API – WebViewGold für iOS

> **Zusammenfassung:** Füge Kalenderereignisse aus deiner Web-App über die iCal-Kalender-API zum nativen iOS-Kalender hinzu.

[Dokumentation](../README.md) › [WebViewGold für iOS](README.md) › iCal-Kalender-API

**Plattform:** iOS · **Kategorie:** APIs & Funktionen · **Online-Version:** [www.webviewgold.com/de/docs/iOS/ical-calendar/](https://www.webviewgold.com/de/docs/iOS/ical-calendar/)

---

WebViewGold ist für eine einfache Integration mit Kalender (früher als iCal bekannt) vorbereitet.

Um einen Kalendereintrag aus deiner WebView-basierten iOS-Anwendung hinzuzufügen, verlinke einfach auf eine .ics-Datei:

```html
<a href="https://www.webviewgold.com/demo/test.ics">Save to Calendar</a>
```

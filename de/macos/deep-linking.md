# Deeplinking API – WebViewGold für macOS

> **Zusammenfassung:** Starte deine WebViewGold-für-macOS-App über ein Custom URL Scheme und öffne direkt eine bestimmte Seite – Deeplinking Schritt für Schritt erklärt.

[Dokumentation](../README.md) › [WebViewGold für macOS](README.md) › Deeplinking API

**Plattform:** macOS · **Kategorie:** APIs & Funktionen · **Online-Version:** [www.webviewgold.com/de/docs/mac/#deeplinking](https://www.webviewgold.com/de/docs/mac/#deeplinking)

---

Deeplinking („Custom URL Scheme“) ist ein leistungsstarker Ansatz, mit dem Benutzer direkt aus einer externen Quelle wie einer Website, einer E-Mail oder einer anderen App zu einer bestimmten Seite oder einem bestimmten Bereich einer App navigieren können. Im Kontext der macOS-App-Vorlage von WebViewGold ermöglicht Deeplinking Entwicklern, Links zu erstellen, die die App starten und Benutzer zu einer bestimmten Seite innerhalb der App führen.\
